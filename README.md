Shivang Kumar | Personal Portfolio Website

About the Project

This is my personal portfolio website created as part of my CodSoft Web Development Internship – Level 1, Task 1. It introduces me, highlights my skills and projects, and provides a way to contact me.

Features

- Responsive website design for desktop and mobile devices
- Home and introduction section
- About me and education section
- Skills and projects sections
- Contact section with an email-based contact form
- Mobile navigation menu

Technologies Used

- HTML5
- CSS3
- JavaScript

Project Files

- "index.html" — Website structure and content
- "style.css" — Styling, layout, and responsive design
- "script.js" — Navigation menu and contact form behavior

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.

You can also use the Live Server extension in Visual Studio Code to preview the website.

Contact Form

The contact form opens the visitor's default email application. It does not directly store or send messages through a website backend.

Customization

Update the education details, skills, and project descriptions with your own information. Add links to your actual projects when available.
