# CodSoft Level 1 — Personal Portfolio

A beginner-friendly responsive portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — colours, layout, and responsive styles
- `script.js` — mobile menu, current year, and demo contact form

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Customize before submitting
- Update the About section with your real education and interests.
- Replace `your.email@example.com` in `index.html` and `script.js` with your own email.
- Add your real GitHub/LinkedIn links and project links.
- Only list skills and projects that accurately represent your experience.
- If you want a profile photo, add your own image and update the HTML/CSS.

## GitHub submission
Create a repository named `CODSOFT_TASK1` (or the exact naming format instructed by your coordinator), upload these files, and share the repository URL in the official submission form when it is provided. The internship PDF says the submission form will be shared later by email.
